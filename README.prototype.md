# ObliGate — UI Prototype

Static HTML prototype of the ObliGate FEMA Public Assistance compliance platform (13 screens, Light/Dark themes, responsive).

- Entry point: `index.html` (Sign In)
- No build step: deploy the folder as a static site (Vercel framework preset: **Other**, output directory: `.`)
- All names, amounts and project numbers in the screens are **sample data**.
